# 日本語の校正

対象: $ARGUMENTS

文法を整えるだけでは足りない。日本語の話者が実際には使わない語、読み手に不要な文、意味の通らない文を見つけ、平易な言葉に置き換えるか削る。

## 1. 一文ずつ確認する

各文について、次の問いにすべて答える。

1. この語を日本語の話者は実際に使うか。直訳調、造語、俗語、比喩は、意味を保ったまま平易な言葉に置き換える。文法が正しくても語を残さない。
   例: 系列、起点、叩き起こす、手組み、素タグ、払った教訓、今日の地図、折り返す、受理、out-of-band 投入
2. 略語はないか。正式名称だけを書く。「正式名称 (略語)」のような併記もしない。例: WIF、TF、FB、CL
3. 削れる文や語はないか。自明な文、コードや PR を見れば分かること、PR 番号、変更の経緯は削る。移動を提案するのではなく、校正後の文章から消す。
4. 意味が一通りに読めるか。何を指すか分からない文は、推測で書き換えない。原文のまま残し、質問に回す。
5. 表記: 英字と日本語の間にスペースを入れない。URL、@メンション、#チャンネルの直後だけは、リンクが日本語まで伸びないようにスペースを残す。太字と絵文字は使わない。バッククォートはコードにだけ使う。

文体 (です・ます、である) は原文に合わせる。依頼がなければ変えない。参考にする文書を渡されたら、先に読んでその文体に合わせる。

## 2. 返答の形

返答は次の3つで構成する。返答自体も 1 の表記ルールに従う。

1. 校正後の文章。そのまま貼り付けられる形で示す。
2. 変更点の表。列は「元」「修正」「理由」とし、理由は一行で書く。
3. 確認したいこと。1-4 で質問に回した箇所について、原文を引用して何を確かめたいかを書く。なければ省く。

ファイルが対象なら、校正後の文章を示すかわりにファイルを直接編集し、表と質問だけを返す。
